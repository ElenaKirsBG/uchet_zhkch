# 🏠 Коммуналка — учёт коммунальных платежей и показаний

© 2026 Елена Кирсанова. Все права защищены — см. файл LICENSE.

Веб-приложение для iPhone, Android и компьютера: показания счётчиков (электричество 1–3 тарифа, вода, газ, свои счётчики), платежи и налоги, тарифы с датой начала, несколько объектов в разных валютах, аналитика, фото квитанций, напоминания, Excel, резервные копии. Работает без интернета, данные хранятся только на устройстве.

Продаётся на сайте: **elenakirsanova.com/kommunal/** — разовая покупка «навсегда», ключ начинается с `KU1-`.
Бесплатно навсегда: показания, платежи, история, резервные копии. PRO: аналитика, тарифы, несколько объектов, фото, напоминания, Excel. Первые 7 дней открыто всё.

## Ваши данные из первой версии

Новая версия читает записи и тарифы **из тех же мест** (`utility_records_data`, `utility_tariff_rules`) и в том же формате. Открыв приложение по прежнему адресу, вы увидите всё, что вносили, — ничего переносить не нужно. При первом запуске приложение само делает автокопию («Ещё → Автокопии»). Файлы JSON, выгруженные из первой версии, тоже восстанавливаются («Ещё → Восстановить из копии»).

## Новый адрес kommunal.elenakirsanova.com (как у других приложений)

1. Cloudflare → **Workers & Pages → Create → Pages → Connect to Git** → репозиторий `uchet_zhkch`.
2. Framework preset: **None**, Build command — пусто, Build output directory — `/` → **Save and Deploy**.
3. **Custom domains → Set up a custom domain** → `kommunal.elenakirsanova.com`.

Как только новый адрес откроется, приложение по старому адресу само покажет подсказку «У приложения новый адрес → Перенести данные» (сначала сохраняется резервная копия, потом данные передаются автоматически или через файл копии на iPhone).

Старый адрес продолжает работать как прежде, пока вы сами его не отключите. Отключать (делать репозиторий приватным) — только после того, как убедитесь, что на новом адресе всё на месте.
